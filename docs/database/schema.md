# Database Schema

BuildPay AI uses SQLModel (SQLAlchemy wrapper) and Alembic for migrations.

Models include:
- `User`
- `Project`
- `BOQ`, `BOQItem`
- `CheckRequest`
- `Measurement`
- `Variation`
- `IPC`, `IPCLine`
- `Approval`
- `AIReview`, `AIFinding`
- `Document`
- `AuditEvent`
- `Notification`
