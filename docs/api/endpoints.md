# Endpoints

Implemented controllers in `/api/v1/`:
- `auth.py`: Login, Register, Get Me.
- `projects.py`: CRUD for Projects.
- `boq.py`: BOQ list and import.
- `check_requests.py`: Check Request lifecycle and AI review triggers.
- `measurements.py`: Measurements tracking.
- `variations.py`: Variation management.
- `ipc.py`: IPC generation and approval.
- `documents.py`: Document upload and retrieval.
- `audit.py`: Audit log access.
- `reports.py`: Dashboard analytics.
- `notifications.py`: User notifications.
