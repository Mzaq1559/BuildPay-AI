# Local Setup

1. **Clone Repo**
2. **Environment**: Copy `.env.example` to `.env` and set `GROQ_API_KEY`.
3. **Start Docker**:
   ```bash
   docker compose up --build
   ```
4. **Access UI**: `http://localhost:3000`
5. **Access API Docs**: `http://localhost:8000/docs`
6. **Stop**: `docker compose down`
