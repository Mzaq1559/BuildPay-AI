# Product Overview

BuildPay AI modernizes construction payments. 

Target Users:
- Contractors
- Consultants
- Quantity Surveyors
- Clients
- Project Managers
- Admins

## Workflows
1. **BOQ Management**: Upload and track Bill of Quantities.
2. **Work Execution**: Contractors submit Check Requests.
3. **Verification**: Consultants review requests and measurements.
4. **Variations**: QS/PM handle scope changes.
5. **Payment**: Generation and approval of IPCs.
