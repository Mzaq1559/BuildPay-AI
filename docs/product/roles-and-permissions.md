# Roles and Permissions

| Role | Description |
|---|---|
| Admin | Full system access |
| Client | Financial oversight, final approvals |
| Project Manager (PM) | Overall project oversight |
| Quantity Surveyor (QS) | Financials, BOQ, IPCs |
| Consultant | Technical verification, QA/QC |
| Contractor | Execution, submits CRs |

*Note: RBAC is implemented via user roles mapped to specific API actions.*
